3. Create the package

Your game's files are packed on all of this computer's cores, the archives with LZ4 and the effects with ZXC (the game reads them as they were), the movies re-encoded to H.265 and the music and effects to Opus (below): about 4.7 GB down to 2.6 GB. The three shaders stored in your game's default.xex are translated here for the Switch; the program carries only the four the game makes while it runs (the Switch compiles all seven in about a second at the first start). The zip downloads while it is written.

4. Copy it to the Switch

  1. If you have an older version, delete its switch//game_root folder first: an unpacked archive left there is used instead of the packed one.
  2. Extract the zip to the root of the SD card: it makes switch//.
  3. In Sphaira, find the game, press X to open Options and choose Install Forwarder. Make sure Address Space is set to 39-bit, choose Create Forwarder, then start the game from the Home Screen. A forwarder made from an earlier version keeps that version's icon: make it again to get the new one.
